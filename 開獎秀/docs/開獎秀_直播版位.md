Status: Living（持續更新，非 Locked）

## 1. 文件定位與範圍

本文件是「開獎秀 → 直播（`live`）」全部版位的集中版位層文件。直播 01～14 統一記錄於本文件，不為個別直播版位建立獨立 Markdown，也不在 `開獎秀/03_直播/docs/` 建立文件。

本文件只記錄已由 Jamie 裁決、Repository 實作或驗證證明的直播版位內容。尚未完成的版位不得自行補充尺寸、格式、欄位、素材、Renderer、Excel、JSON、ZIP 或驗證結果。

平台層、共用控制台與 Architecture Contract 依既有正式規格及 Locked 文件為準；本文件只記錄直播版位層內容。

## 2. 直播共通邊界

- 直播項目 ID：`live`。

Phase 2 僅允許在區塊一、區塊二的單一行文字上拖曳選取；警語、Logo 與背景不可選取。ranges 儲存於 06 state 的每欄每行 Unicode code-point index，支援同一行多段範圍，並於套用時正規化合併重疊或相鄰 ranges。跨行或跨區塊拖曳不套用反選。

放開滑鼠後由 DOM 互動層顯示浮動螢光筆按鈕；點擊後才套用或取消反選。暫時反白及浮動按鈕不進入 JPG。反選只改文字前景色，不改字型、字距、文字位置或 Canvas 尺寸。區塊文字修改只清除該區塊 ranges；一般色、背景色及警語色修改不清除 ranges；切換 smart-locker／store 時保留文字與 ranges，套用該樣式顏色。

右側四色控制為背景色、一般文字色、反選文字色、警語文字色。Preview 與 JPG Export 均傳入同一份文字、ranges 與顏色 state，並使用共用 `renderLiveToCanvas`；Renderer 先以一般色繪製整行，再以 clip 重繪反選色，以保留原字型與 kerning。
